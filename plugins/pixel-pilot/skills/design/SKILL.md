# /design

Design work: critique, design system, dev handoff, UX copy, accessibility (WCAG AA), research plans and synthesis.

## Usage

Pick the mode from the request or the `/design` argument. If none matches, ask with options. Read only that one reference.

| Mode | Triggers | Reference |
|------|----------|-----------|
| critique | review or critique a design, mockup or screen | references/design-critique.md |
| system | audit, document or extend a design system or component | references/design-system.md |
| handoff | developer handoff spec: layout, tokens, states, breakpoints | references/design-handoff.md |
| copy | microcopy, error messages, empty states, CTA and button text | references/ux-copy.md |
| accessibility | WCAG 2.1 AA audit: contrast, keyboard, touch targets, screen readers | references/accessibility-review.md |
| research | synthesize interviews, surveys, tickets and NPS into themes | references/research-synthesis.md |
| users | plan research: interview guide, usability test, survey | references/user-research.md |
