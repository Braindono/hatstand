# pixel-pilot

Design work plugin: critique, design system, dev handoff, UX copy, accessibility (WCAG AA), research plans and synthesis.

## Usage

Use the `/design` skill or any of these modes:

- Critique: `/design critique <description>`
- Design System: `/design system <task>`
- Handoff: `/design handoff <deliverable>`
- UX Copy: `/design copy <task>`
- Accessibility: `/design accessibility <design>`
- Research Synthesis: `/design research <topic>`
- User Research: `/design users <task>`
