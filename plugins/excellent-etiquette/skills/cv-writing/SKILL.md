# cv-writing

- [project:cv-management] P-10 Open items per posting: one table # / Type (Q/S/D) / Item / Conf (H/M/L), short cells.
- [project:cv-management] P-11 Many edits: one at a time, "Item N of M".
- [project:cv-management] P-12 Calling out part of a paragraph: show the whole paragraph.
- [project:cv-management] P-13 Before/After: blockquote paragraphs; color only changed words (red old, green new).
- [project:cv-management] P-14 After each Before/After: # / Rationale / Conf table (H KB or his words, M judgment, L speculative).
- [project:cv-management] P-15 Saved-job fit: analyze all jobs at once; ask one job per turn.
- [project:cv-management] P-37 Run polished-prose on resume/letter prose before fit-check and on drafts; if missing, stop and report.
- [project:cv-management] P-38 Keep the writer's adverbs; polish must not strip them.
- [project:cv-management] P-55 Post-graduate vocabulary; temper on resumes.
- [project:cv-management] P-56 Active voice.
- [project:cv-management] P-57 Keep casual flair ("really," "happily," opening "And"); no flat colloquialisms.
- [project:cv-management] P-58 Vary key words unless every substitute is clunky ("led" twice).
- [project:cv-management] P-59 No em dashes; use semicolons or separate clauses.
- [project:cv-management] P-60 Restrained, precise phrasing; no theatrical structure.
- [project:cv-management] P-61 If Re: names the role, skip "I am writing to apply for".
- [project:cv-management] P-62 Frame technical depth as systems architecture and integration, not programming.
- [project:cv-management] P-63 Apply inline edits exactly; offer smallest fix, flag side effects.
- [project:cv-management] P-64 Open drafts as a side-panel Claude Doc; apply edits to the draft file.
- [project:cv-management] P-74 Resumes to CV_Management/Claude outputs/resumes/<YYYY-MM-DD>/<Company>/ (untailored: Base): pdf, docx, html, _build/.
- [project:cv-management] P-75 Letters to .../letters/<YYYY-MM-DD>/<Company>/, .md beside pdf.
- [project:cv-management] P-76 Filenames start with btf_, never Brian_Frederick_.
- [project:cv-management] P-77 Superseded files to resumes/ or letters/_archive; never delete.
- [project:cv-management] P-78 Listings: listings_dir/<YYYY-MM-DD>/<company>-<slug>.md, one top-level manifest.md.
- [project:cv-management] P-79 Skills JSON at top of CV_Management/; several files in CV_Management/operator stats/.
