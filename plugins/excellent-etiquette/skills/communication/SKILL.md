# communication

- [global] P-01 Be compressed and structured: summaries and tables, not raw transcripts or tool output; turn machine output into tables with your own suggestions.
- [global] P-02 Always give your recommendation, not just data.
- [global] P-03 State each decision's token cost and the difference between options; plans show token estimates.
- [global] P-04 Never show harness ids (D-/N-/K-/m-) or bare codes (R1-R14, W45, hk3) alone; say it in words, with where and how to answer; code in parentheses; example: references/more.md.
- [global] P-05 Address mail to the role (to=role:<name>), never an agent id or sobriquet; roster: harness_admin op=roster.
- [global] P-06 Present questions and suggestions as selectable options (AskUserQuestion), not plain-text lists.
- [global] P-07 Number questions n/N (1/2, 2/2) by default (P-11 only inside cv-management edits).
- [global] P-08 Put the recommended option first, labelled "(Recommended)".
- [global] P-09 Tag every answer or option with confidence: green High, yellow Medium, white Low.
- [global] P-96 Every open question you raise carries your suggestion and a default; work a pending list without asking permission (extends P-92).
- [global] P-97 A table needing more than one operator action is a questionnaire (categorical answers, info-only rows), never a prose table; daily checklist and action-items file: references/more.md.
- [global] P-98 A local file or folder pointed to in chat is a markdown link with a computer:// URL (example: references/more.md), never a bare path; where links cannot render, give the full absolute path in a code block.
- [global] P-99 A command for the operator: ONE fenced block, one line; a dry run goes ALONE first, the next command only after its result; a prompting command (approve) is one per id, never a loop. His steps go to role:secretary's Hub queue, unless he asks in chat: references/more.md.
- [global] P-100 While waiting on an agent's reply, show one status line in chat: who, about what, next step (D-3a5b3).
- [global] P-102 Be skeptical of your own plans: say what is unverified; full rule: references/more.md.
- [global] P-103 A tool the operator names describes the goal: restate the goal in one line before designing; say when a better way exists, with the trade-off (D-24743).
- [global] Operator tables: first column A-Z or 0-9 row labels, stable on re-show.
