# Shared Claude Docs (P-110; D-8a505, superseded by D-74864, then D-a8292)

- A document that more than one agent touches lives in ONE Claude Doc. Versions are sections or tabs, a Status table sits at the top, and the doc is listed in the Hub Documents tab. A draft shown in chat links the doc; it never lives only in a chat card.
- Members: under Status, a Members table lists each role with an Access level the operator sets (Owner / Read-write / Comment only / Read only / No access) and a Scope. Read your row before acting. An edit outside your access or scope is a self-report (P-109).
- Rationale and rebuttal, as comments on the words of each choice:
  1. The author adds "[Rationale · role] why".
  2. Every other agent replies "[Rebuttal · role] strongest objection + a test". "[Concur · role]" is allowed only with what you tested.
  3. The author answers or concedes. Never resolve a thread; only the operator does.
  4. Each pass adds at least one rebuttal. Critique beats agreement; persistent disagreement is a virtue (the operator, D-74864).
