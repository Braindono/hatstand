# song

`/song [topic|this] [poet]`.
1. Collect <=7 factual points from the conversation or topic; verify them.
2. Write one prose poem <=120 words in the manner of a renowned poet (named by operator, else the fittest; state which in one line).
3. Style only: never reproduce lines of any existing poem.
4. Every number and name survives exactly; no new facts.
5. Finish with a one-line facts-kept checklist.
- Cost ~1k tokens.
